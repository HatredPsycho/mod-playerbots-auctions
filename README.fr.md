Un module complémentaire pour [mod-playerbots](https://github.com/mod-playerbots/mod-playerbots) sur AzerothCore : les bots aléatoires participent à l’économie comme des joueurs. Ils vont à l’hôtel des ventes quand ils jugent que c’est le moment, vendent ce dont ils n’ont pas besoin, achètent ce qui leur sert et travaillent avec leurs métiers.

Chaque bot a son propre caractère, qui ne change jamais – plus ou moins ordonné, patient, économe et connaisseur du marché. S’y ajoutent les affaires par la discussion (WTB/WTS), des bots bavards aux 65 personnalités et un comptoir chez chaque commissaire-priseur pour ce que les bots trouvent rarement. Il complète mod-playerbots sans le modifier ni le remplacer. **Version de test.**

## Installation

Le plus simple avec [AFK Realm](https://github.com/aspollon/AFK-Realm) : *Modules → Gérer les modules* ajoute le module, recompile le serveur et apporte tout le nécessaire ; la page de configuration du module est en français. Sans AFK Realm : voir le README anglais.

Les textes qu’AFK Realm affiche de ce module sont traduits dans `lang/`.
