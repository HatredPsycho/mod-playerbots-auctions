# mod-playerbots-auctions

[English](README.md) · [Deutsch](README.de.md) · [Français](README.fr.md) · [Español](README.es.md) · [Português (Brasil)](README.pt-BR.md) · [Русский](README.ru.md) · **简体中文**

*简短版——完整说明见[英文 README](README.md)。*

一个用于 AzerothCore 上 [mod-playerbots](https://github.com/mod-playerbots/mod-playerbots) 的附加模块：随机机器人像玩家一样参与经济。它们会在自己觉得合适时前往拍卖行，卖掉用不上的东西，买下用得上的东西，并用自己的专业制造物品。

每个机器人都有固定不变的性格——是否爱整洁、有耐心、节俭、懂行情。此外还有通过聊天进行的交易（WTB/WTS）、拥有 65 种性格的会聊天的机器人，以及每个拍卖师处为机器人难以获得的东西设立的贸易站。它是对 mod-playerbots 的补充，不会修改或取代它。**测试版。**

## 安装

最简单的方式是使用 [AFK Realm](https://github.com/aspollon/AFK-Realm)：在“模块 → 管理模块”中添加本模块，它会重新编译服务器并带上所需的一切；本模块的设置页面提供简体中文。不使用 AFK Realm：请参阅英文 README。

AFK Realm 显示的本模块文本已翻译在 `lang/` 中。
