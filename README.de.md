Ein Zusatzmodul für [mod-playerbots](https://github.com/mod-playerbots/mod-playerbots) auf AzerothCore: Die Zufallsbots nehmen wie Spieler an der Wirtschaft teil. Sie gehen ins Auktionshaus, wenn sie es für an der Zeit halten, verkaufen, was sie nicht brauchen, kaufen, was sie gebrauchen können, und arbeiten mit ihren Berufen.

Jeder Bot hat einen eigenen Charakter, der sich nie ändert – wie ordentlich, geduldig, sparsam und marktkundig er ist. Dazu kommen Geschäfte per Chat (WTB/WTS), plaudernde Bots mit 65 Persönlichkeiten und ein Handelsposten bei jedem Auktionator für das, was Bots kaum finden. Es ergänzt mod-playerbots, ohne es zu ändern oder zu ersetzen. **Testversion.**

## Installation

Am einfachsten mit [AFK Realm](https://github.com/aspollon/AFK-Realm): *Module → Module verwalten* fügt das Modul hinzu, baut den Server neu und bringt alles Nötige mit; die Einstellungsseite des Moduls ist auf Deutsch. Ohne AFK Realm: siehe das englische README.

Die Texte, die AFK Realm von diesem Modul zeigt, liegen übersetzt in `lang/`.
